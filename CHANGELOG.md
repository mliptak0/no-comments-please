## [0.1.0] - 2026-11-17

### Added

- Initial release: preview without comments for files and diffs.
- Toggle via title-bar eye icon and `Ctrl+Alt+.` / `Cmd+Alt+.`.
- Inline preview option (`noCommentsPlease.openPreviewInline`).
- 40+ language support via semantic tokens + heuristic fallback.
- Whole-line comments vanish (indent + newline), inline comments keep code.
- Cartoon ghost icons (light/dark) and marketplace branding.
